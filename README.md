# Real-Engine (v2)
An implementation of a 3D rendering engine written in plain Java, and JOCL for GPU Accelerated rendering. This project was created by me for my Grade 11 Introduction to Computer Science Summative (Ontario).
*Note: This version of Real-Engine requires OpenCL, and contains unfinished physics engine code. This version also removes the ability to add Cosine and Tangent functions to the rendering output like in the original version. This version also changes the representation of the eye from planar to spherical.*

---

## Features
- Ability to spawn in Cubes during run-time
- Jumping and movement
- Collision detection (Finished in Craft Me IN)
- Custom Rendering Engine
- Abiilty to change focal length

---

## Dependencies
- JDK version 17+
- GUI elements
- JOCL

## Build
Download the zipped project folder in releases, and use Maven to download the required dependencies.

Ensure you have OpenCL installed on your computer.
